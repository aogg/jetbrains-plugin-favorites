# PhpStorm 收藏功能详细文档

## 功能概述

PhpStorm 的收藏（Bookmarks，也称为书签）功能是一个强大的代码导航工具，用于在大型项目中快速定位常用的代码行、文件和文件夹。所有收藏都集中在 Bookmarks 工具窗口中统一管理，极大提升了开发效率。

## 收藏类型

### 1. 匿名收藏（Anonymous Bookmarks）

- **特点**：没有标识符，可以添加任意数量
- **显示方式**：在编辑器中用书签图标（📑）标记在代码行左侧
- **适用场景**：临时标记需要回顾的代码位置，不需要快速跳转的场景

### 2. 助记符收藏（Mnemonic Bookmarks）

- **特点**：使用数字（0-9）或字母（A-Z）作为标识符
- **显示方式**：在代码行左侧显示带框的字母或数字图标（如 `[1]`、`[A]`）
- **适用场景**：需要快速跳转的常用位置，可以通过快捷键直接访问
- **限制**：每个标识符只能使用一次，总共最多 36 个（10 个数字 + 26 个字母）

## 添加收藏的方式

### 代码行收藏

#### 匿名收藏
1. **快捷键方式**：将光标放在目标代码行，按 `F11`
2. **右键菜单**：右键单击行号区域，选择 "Add Bookmark"
3. **移除方式**：再次按 `F11` 或右键选择 "Remove Bookmark"

#### 助记符收藏
1. **快捷键方式**：将光标放在目标代码行，按 `Ctrl+F11`
2. **操作步骤**：
   - 弹出窗口显示可用的数字和字母
   - 选择要使用的标识符（数字 0-9 或字母 A-Z）
   - 可选：添加描述文字，便于识别
   - 按 `Enter` 确认或 `Esc` 取消
3. **移除方式**：再次按 `Ctrl+F11` 选择相同标识符，或通过 Bookmarks 工具窗口删除

### 文件和文件夹收藏

1. **打开项目工具窗口**：按 `Alt+1` 或通过菜单 `View | Tool Windows | Project`
2. **添加方式**：
   - 右键单击文件或文件夹
   - 选择 `Bookmarks | Add Bookmark (F11)` 添加匿名收藏
   - 或选择 `Add Mnemonic Bookmark (Ctrl+F11)` 添加助记符收藏
3. **批量添加**：可以同时选择多个文件或文件夹，一次性添加收藏

### 编辑器标签收藏

1. **添加方式**：
   - 右键单击编辑器标签页
   - 选择 `Bookmarks | Add Bookmark` 或 `Add Mnemonic Bookmark`
2. **批量添加**：可以为所有打开的标签页创建收藏并添加到新列表

## 访问和管理收藏

### Bookmarks 工具窗口

- **打开方式**：
  - 菜单：`View | Tool Windows | Bookmarks`
  - 快捷键：`Alt+2`
- **功能**：
  - 查看所有收藏（代码行、文件、文件夹）
  - 双击收藏项快速跳转到对应位置
  - 右键菜单可以编辑、删除收藏
  - 可以重命名助记符收藏的描述

### 快速访问行收藏

- **快捷键**：`Shift+F11`
- **功能**：弹出窗口显示所有代码行收藏，可以快速选择跳转
- **菜单路径**：`Edit | Bookmarks | Show Line Bookmarks`

### 跳转到助记符收藏

- **快捷键**：`Ctrl + [数字/字母]`
- **示例**：如果创建了标识符为 `1` 的收藏，按 `Ctrl+1` 即可快速跳转

## 高级功能

### 上下文（Contexts）功能

收藏可以与任务关联，形成工作上下文（Context）：

- **功能说明**：
  - 一个上下文包含一组收藏、断点和打开的编辑器标签
  - 允许在不同工作任务之间无缝切换
  - 保存当前工作状态，稍后可以快速恢复

- **使用方法**：
  - 菜单路径：`Tools | Tasks & Contexts`
  - 可以保存、加载或清除上下文
  - 适合在多个功能模块或任务之间切换

### 高级设置

在 `Settings | Advanced Settings` 中可以配置：

- **"Show only line bookmarks in popup"**：
  - 启用后，`Shift+F11` 弹出窗口仅显示代码行收藏
  - 禁用后，弹出窗口会显示所有类型的收藏（包括文件和文件夹）

## 快捷键汇总

| 快捷键 | 功能 |
|--------|------|
| `F11` | 添加/移除匿名收藏（代码行） |
| `Ctrl+F11` | 添加/移除助记符收藏（代码行） |
| `Alt+2` | 打开/关闭 Bookmarks 工具窗口 |
| `Shift+F11` | 显示行收藏弹出窗口 |
| `Ctrl + [0-9/A-Z]` | 快速跳转到对应助记符收藏 |
| `Alt+1` | 打开 Project 工具窗口（用于添加文件/文件夹收藏） |

## 使用场景和最佳实践

### 推荐使用场景

1. **代码审查**：标记需要检查的代码行
2. **调试定位**：标记可能出现问题的代码位置
3. **功能开发**：标记相关文件，快速在多个文件间切换
4. **学习代码**：标记重要或难以理解的代码段
5. **重构工作**：标记需要修改的相关代码位置

### 最佳实践

1. **助记符收藏**：用于最常用的位置（如主入口文件、配置文件等）
2. **匿名收藏**：用于临时标记，定期清理不需要的收藏
3. **描述信息**：为助记符收藏添加有意义的描述，便于识别
4. **上下文管理**：使用上下文功能管理不同任务的工作状态
5. **定期整理**：定期清理不再需要的收藏，保持工具窗口整洁

## 注意事项

1. **助记符限制**：每个标识符（0-9, A-Z）只能使用一次，总共最多 36 个助记符收藏
2. **匿名收藏数量**：理论上无限制，但过多会影响性能和管理
3. **收藏持久化**：收藏信息保存在项目配置中，通常位于 `.idea` 目录
4. **版本控制**：`.idea` 目录通常不提交到版本控制，收藏信息是本地配置
