## Description（英文，建议 Marketplace 展示用）
Favorites is a bookmark plugin for PhpStorm.
- Anonymous bookmarks: unlimited bookmarks, shown as gutter icons in the editor.
- Mnemonic bookmarks: use digits (0-9) or letters (A-Z) as identifiers, up to 36.
- Favorites tool window: manage all bookmarks in one place.
- Quick access: jump to a bookmark from a popup with keyboard navigation and search.

## Description（中文）
收藏插件 - 提供代码行、文件和文件夹的收藏功能，支持匿名收藏和助记符收藏。
功能包括：
- 匿名收藏：无限制数量的收藏，在编辑器行号区域显示书签图标
- 助记符收藏：使用数字（0-9）或字母（A-Z）作为标识符，最多36个
- 收藏管理工具窗口：统一管理所有收藏
- 快速访问：弹出窗口快速跳转到收藏位置
