# PhpStorm 插件上架 JetBrains Marketplace 流程

以本插件（Favorites / com.aogg.favorites）为例。

## 1. 前置检查
- plugin.xml 关键字段（src/main/resources/META-INF/plugin.xml）：
  - `<id>`：com.aogg.favorites，全市场唯一
  - `<name>`：Favorites
  - `<version>`：与 build.gradle.kts 保持一致（当前 1.0.12）
  - `<idea-version>`：since-build="233" until-build="262.*"（PhpStorm 2023.3 ~ 2026.2）
  - `<description>`：Marketplace 面向全球用户，建议改用英文（翻译见 资料/发布信息.md）
- 本地打包：`./gradlew buildPlugin`，产物 zip 在 `build/distributions/jetbrains-plugin-favorites-<version>.zip`

## 2. 注册
- 用 JetBrains 账号登录 plugins.jetbrains.com

## 3. 签名准备（Marketplace 要求插件必须签名）
- 本地生成密钥对并导出证书：
  ```bash
  keytool -genkeypair -alias favorites -keyalg RSA -keysize 4096 -keystore favorites.jks -validity 3650
  keytool -exportcert -alias favorites -file favorites.cer -keystore favorites.jks
  ```
- Marketplace 账号 → My Plugins → Plugin Signing，上传 favorites.cer
- 对应 build.gradle.kts `signPlugin` 读取的环境变量：
  - `CERTIFICATE_CHAIN`：证书链文本
  - `PRIVATE_KEY`：私钥文本
  - `PRIVATE_KEY_PASSWORD`：私钥密码
- 签名：`./gradlew signPlugin`，产出已签名 zip（build/distributions/）

## 4. 获取 Publish Token
- Marketplace 账号 Settings → Tokens → Generate Token，即 `PUBLISH_TOKEN`

## 5. 上架（两种方式二选一）
### a) 网页上传
1. 插件页 → Upload plugin，上传签名 zip
2. 填写名称、Description、Change Notes（可勾选"使用插件 zip 内的描述/变更说明"）
3. 提交审核

### b) 命令行
```bash
export CERTIFICATE_CHAIN=... PRIVATE_KEY=... PRIVATE_KEY_PASSWORD=... PUBLISH_TOKEN=...
./gradlew publishPlugin
```

## 6. 审核
- 通常 1~2 个工作日，通过后自动上线
- 上线后 PhpStorm 内置插件市场即可搜到 Favorites

## 7. 更新版本（简短）
1. 改 build.gradle.kts 与 plugin.xml 的 version
2. 更新 plugin.xml 的 change-notes
3. 重新 `./gradlew buildPlugin` + `publishPlugin`（网页方式则重新上传 zip）
