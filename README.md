# JetBrains Plugin - Favorites

收藏插件 - 为 PhpStorm 提供代码行、文件和文件夹的收藏功能，参照 PhpStorm 原生 Bookmarks 提供列表（Lists）分组能力，行为尽量与原生保持一致，但通过独立插件实现。

## 功能特性

- **双作用域收藏（1.2.0）**：收藏分为「项目收藏」（随项目走，存相对路径于 `.idea/favorites.xml`）与「全局收藏」（跨项目共享，存绝对路径于 IDE 配置目录 `favorites.global.xml`）；添加收藏时二选一（默认高亮上次选择并记住）；右键"移动到列表"支持跨作用域转移（路径自动换算，全局→项目仅限项目内路径，助记符冲突自动降级为匿名）
- **收藏列表（Lists）**：参照 PhpStorm 原生 Bookmarks 的列表分组，支持新建/重命名/删除列表、收藏跨列表移动；默认列表"收藏"不可删除，删除列表时其收藏自动并入默认列表；两个作用域各自拥有独立列表
- **PhpStorm 风格树状视图（1.3.0）**：收藏树按 作用域 → 列表 → 文件系统树 展示：按收藏路径生成上级目录虚拟链；行收藏挂在其所在文件的文件节点下（`行号: 行内容`）；文件收藏即文件节点本体（同路径行收藏合并为子节点）；文件夹收藏可展开并懒加载真实子文件/子文件夹（含未收藏项，逐级展开）；图标按 IDE 文件类型呈现（.php/.bat/.sql 等），主文本右侧附灰色说明（行内容/父目录路径/收藏路径）
- **匿名收藏**：无限制数量的收藏，在编辑器行号区域显示书签图标（同时匹配项目/全局两个作用域）
- **助记符收藏**：使用数字（0-9）或字母（A-Z）作为标识符，最多36个；助记符在所属作用域内全局唯一（跨列表），跳转快捷键先查项目作用域、再查全局作用域
- **收藏管理工具窗口**：PhpStorm 风格树状视图 + 实时过滤（含作用域名）+ 排序（按列表记忆，两作用域独立）+ 速度搜索 + 收藏设置按钮
- **快速访问**：弹出窗口快速跳转到收藏位置（按「项目收藏」「全局收藏」分组，组内沿用列表名）
- **导入原生书签**：一键导入 PhpStorm 原生书签（运行时 API + .idea XML 容错解析双通道，自动去重、增量合并，助记符随迁）
- **隐藏原生书签入口**：默认接管 F11/Ctrl+F11/Shift+F11/Alt+2/Ctrl+0-9 等原生键位并隐藏原生 Bookmarks 工具窗口（可在设置中关闭并完整恢复）
- **多入口支持**：编辑器右键、行号区右键、项目视图右键、编辑器标签页右键均有"收藏"子菜单
- **旧数据迁移**：升级后旧 favorites.xml 中无列表信息的收藏自动归入默认列表，不丢数据

## 使用说明

### 支持的收藏类型

- **匿名收藏**：
  - 无标识符，数量不限
  - 推荐用于临时标记、审查点、调试观察点等
- **助记符收藏**：
  - 使用数字 `0-9` 和字母 `A-Z` 作为标识符（最多 36 个，所属作用域内全局唯一）
  - 推荐用于常驻、需要快速跳转的位置

### 双作用域（1.2.0）

- **项目收藏**：保存在 `.idea/favorites.xml`，随项目走，换台电脑/换个项目不跟随
- **全局收藏**：保存在 IDE 配置目录 `favorites.global.xml`，跨项目共享（存绝对路径，可在任何项目中跳转）
- **添加时选择**：添加匿名/助记符收藏时弹出「项目收藏 / 全局收藏」二选一，默认高亮上次使用的作域并自动记住；项目视图多选批量只弹一次选择，全部加入同一作用域；同一位置已有收藏时维持原有切换（直接移除）语义
- **跨作用域转移**：右键收藏 → "移动到列表" → 展开另一作用域的列表组选择目标列表；全局→项目时若收藏位于项目目录之外会提示失败；转移后助记符在目标作用域冲突时自动降级为匿名收藏

### 收藏列表

- 新建列表：工具窗口右键 → "新建列表"（加入当前选中的作用域）
- 重命名列表：右键列表（或列表中的收藏）→ "重命名列表"（默认列表"收藏"不可重命名）
- 删除列表：右键列表 → "删除列表"，其中的收藏自动并入默认列表，**不会丢失数据**
- 移动收藏：右键收藏 → "移动到列表" → 按作用域分组选择目标列表（支持跨作用域转移）
- 排序：工具窗口右上角排序下拉（按添加顺序 / 按描述 / 按位置），**按列表记忆并持久化**（两个作用域各自独立）

### 快捷键（默认键位）

| 功能 | 默认键位 |
|---|---|
| 添加/移除匿名收藏（编辑器上下文） | `Ctrl+Alt+F11` |
| 添加/移除助记符收藏（编辑器上下文） | `Ctrl+Alt+Shift+F11` |
| 显示/隐藏收藏工具窗口 | `Alt+2` |
| 显示收藏弹出列表 | `Ctrl+Alt+Shift+B` |
| 跳转到助记符收藏 [0-9, A-Z] | `Ctrl+Alt+0-9` / `Ctrl+Alt+A-Z` |
| 工具窗口内：跳转 | `Enter` / 双击 |
| 工具窗口内：编辑描述 | `F2` |
| 工具窗口内：删除 | `Del` |

> 说明：默认配置下，PhpStorm 原生书签的以下键位由本插件**接管**（原生动作 id 不变，用户自定义键位映射保留）：
>
> | 原生键位 | 原生动作 id | 接管后行为 |
> |---|---|---|
> | `F11` | `ToggleBookmark` | 添加/移除匿名收藏 |
> | `Ctrl+F11` | `ToggleBookmarkWithMnemonic` | 添加/移除助记符收藏 |
> | `Shift+F11` | `ShowBookmarks` | 收藏弹出列表 |
> | `Alt+2` | `ActivateBookmarksToolWindow` | 收藏工具窗口开关 |
> | `Ctrl+0-9`（存在时含 `Ctrl+A-Z`） | `GotoBookmark0-9`（`GotoBookmarkA-Z`） | 跳转到对应助记符收藏 |
>
> 同时隐藏未接管的残余原生动作（`ToggleBookmark0-9`/`ToggleBookmarkA-Z` 等）与原生 `Bookmarks` 工具窗口。
> **默认开启**，可在 `Settings → Tools → Favorites` 关闭"隐藏 PhpStorm 原生书签入口"，关闭后原生动作与工具窗口立即恢复。
> 所有键位仍可在 IDE `Settings | Keymap` 中自行修改。

### 导入原生书签

- **入口**：收藏工具窗口工具栏"导入原生书签"按钮，或右键"收藏"子菜单 → "导入原生书签"
- **双通道读取**（尽力而为）：
  - 通道一（首选）：运行时 `BookmarksManager` API 读取原生书签（url/行号/助记符/所属列表）
  - 通道二（兜底）：容错解析 `.idea/bookmarks.xml` / `.idea/workspace.xml`（组件 `BookmarksManager`）与旧版 `.idea/favorites.xml` 收藏列表
- **导入规则**：
  - 行书签 → 行收藏；文件/文件夹书签 → 对应收藏
  - 原生列表名存在则同名创建收藏列表，否则进"原生书签"列表
  - 原生助记符随迁；已被现有收藏占用时降级为匿名收藏
  - 与现有收藏按（相对路径+行号）/路径去重，**可重复执行（增量合并），不产生重复**
- **结果通知**：`已导入 N 条原生书签（新建 M 个列表，跳过重复 K 条）`，点击[查看]打开收藏工具窗口
- **首次引导**：打开项目检测到原生书签且未导入过时，弹出通知 `检测到 N 条 PhpStorm 原生书签，可一键导入到本插件`，可选[立即导入]或[不再提示]；可在设置页用"重置导入提示"重新触发

### 隐藏原生书签入口

- **默认开启**：接管上表所列原生键位（动作 id 不变，键位映射保留），隐藏 `ToggleBookmark0-9`/`ToggleBookmarkA-Z`/`ShowTypeBookmarks` 等残余原生动作、原生 `Bookmarks` 动作组与原生 `Bookmarks` 工具窗口（含"被显示就再藏"的兜底监听）
- **关闭方式**：`Settings → Tools → Favorites` 取消勾选"禁用 PhpStorm 原生书签功能"并 Apply —— 原生动作、动作组与工具窗口立即恢复
- 隐藏为尽力而为：任何一步失败仅记录日志，不影响插件其它功能

### 入口与场景

- **编辑器 / 行号区（Gutter）/ 项目视图 / 编辑器标签页右键**：
  - 均有"收藏"子菜单（菜单置底），内含"添加匿名收藏 / 添加助记符收藏"
  - 编辑器上下文 → 行收藏；项目视图/标签页 → 文件/文件夹收藏；无有效上下文时菜单项自动隐藏
- **项目视图（Project Tool Window）**：支持多选批量收藏
- **收藏工具窗口 `Favorites`**（默认停靠在左侧）：
  - 作用域 → 列表 → 文件系统树（上级目录链/文件/行收藏/文件夹懒加载），作用域节点显示总数徽标，如 `项目收藏 (12)`
  - 顶部搜索框实时过滤（按作用域名/描述/文件名/路径/列表名，过滤后目录树按命中项重建），支持 `TreeSpeedSearch` 输入即搜
  - 工具栏：添加收藏、添加助记符、编辑描述、删除、全部展开/折叠、收藏设置（齿轮，直达设置页）
  - 右键菜单：跳转 / 编辑描述 / 设置助记符 / 移动到列表▸（按作用域分组）/ 新建列表 / 重命名列表 / 删除列表 / 删除收藏
  - 交互：`Enter`/双击=跳转（行→编辑器定位；文件夹→Project 视图选中）；`F2`=编辑描述；`Del`=删除；选中行收藏时预览打开文件但不抢焦点
- **助记符选择对话框**：`0-9/A-Z` 网格按钮，已占用项置灰禁用（按所选作用域检测），可输入描述
- **设置页**：`Settings → Tools → Favorites`
  - ☑ 禁用 PhpStorm 原生书签功能（默认禁用；F11/Ctrl+F11/Shift+F11/Alt+2 等由本插件接管，apply 立即生效/恢复）
  - 按钮"重置导入提示"：清空已导入/不再提示标记，重新触发首次引导

### 收藏管理

- **收藏工具窗口 `Favorites`**：统一按列表管理所有收藏（行 / 文件 / 文件夹）
- **快速访问弹出 `收藏列表`**：使用 `Ctrl+Alt+Shift+B` 打开，支持键盘导航和输入过滤

## 构建说明

### 方式一：使用 IntelliJ IDEA（推荐）

1. 在 IntelliJ IDEA 中打开项目
2. IDE 会自动下载 Gradle wrapper
3. 在 Gradle 工具窗口中运行 `buildPlugin` 任务
4. 插件包将生成在 `build/distributions/` 目录，并自动同步复制到项目根 `distributions/` 目录

### 方式二：使用命令行

```bash
# Windows
gradlew.bat buildPlugin

# Linux/macOS
./gradlew buildPlugin
```

### 方式三：使用便捷打包脚本 bin/build.sh（推荐）

脚本自动定位 JDK17（JAVA_HOME → PATH → /usr/lib/jvm/java-17*）并执行 Gradle 打包：

```bash
# 默认执行 buildPlugin
bash bin/build.sh

# 先跑单元测试再打包
bash bin/build.sh --test

# 打包前先 clean；其余参数原样透传给 gradlew
bash bin/build.sh --clean
bash bin/build.sh --clean --test
bash bin/build.sh --clean buildPlugin --console=plain
```

构建成功后打印插件 zip 的绝对路径、大小与 sha256。zip 会同步输出到项目根 `distributions/` 目录（`build/distributions/` 仍是 Gradle 原始输出位置，CI 发布继续使用它）。

## 安装插件

1. 构建完成后，在项目根 `distributions/`（或 `build/distributions/`）目录找到生成的 zip 文件
2. 在 PhpStorm 中：`File` -> `Settings` -> `Plugins` -> `Install Plugin from Disk`
3. 选择生成的 zip 文件进行安装
4. 重启 PhpStorm
