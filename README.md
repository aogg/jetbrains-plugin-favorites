# JetBrains Plugin - Favorites

收藏插件 - 为 PhpStorm 提供代码行、文件和文件夹的收藏功能，参照 PhpStorm 原生 Bookmarks 提供列表（Lists）分组能力，行为尽量与原生保持一致，但通过独立插件实现。

## 功能特性

- **双作用域收藏（1.2.0）**：收藏分为「项目收藏」（随项目走，存相对路径于 `.idea/favorites.xml`）与「全局收藏」（跨项目共享，存绝对路径于 IDE 配置目录 `favorites.global.xml`）；添加收藏时二选一（默认高亮上次选择并记住）；右键"移动到列表"支持跨作用域转移（路径自动换算，全局→项目仅限项目内路径，助记符冲突自动降级为匿名）
- **收藏列表（Lists）**：参照 PhpStorm 原生 Bookmarks 的列表分组，支持新建/重命名/删除列表、收藏跨列表移动；默认列表"收藏"不可删除，删除列表时其收藏自动并入默认列表；两个作用域各自拥有独立列表
- **PhpStorm 风格树状视图（1.3.0）**：收藏树按 作用域 → 列表 → 文件系统树 展示：文件/行收藏按收藏路径生成上级目录虚拟链（1.6.1 起文件夹收藏从它自己开始显示、不再生成上级目录链）；行收藏挂在其所在文件的文件节点下（`行号: 行内容`）；文件收藏即文件节点本体（同路径行收藏合并为子节点）；文件夹收藏可展开并懒加载真实子文件/子文件夹（含未收藏项，逐级展开）；图标按 IDE 文件类型呈现（.php/.bat/.sql 等），主文本右侧附灰色说明（行内容/父目录路径/收藏路径）
- **规则匹配（1.4.0）**：树第一层新增第三根节点「规则匹配」（与项目收藏/全局收藏同级），支持三类规则：**正则**（遍历项目内相对路径 find，目标可按 仅文件/仅文件夹/全部 过滤，结果达上限即停防卡顿）、**SQL**（IDE 数据源优先 + 手动 JDBC 兜底，驱动缺失时从驱动 jar 动态加载，密码经 PasswordSafe 不落盘，可选"路径列"跳转）、**SSH**（读现有配置双通道：IDE SSH Configurations + `~/.ssh/config`，本机 ssh 执行自定义命令按行展示，v1 仅密钥/agent 认证）；规则节点带状态徽标（✅N/⏳/❌ tooltip=失败原因）；工具栏「新建规则」「刷新规则」（全刷新）、右键「刷新此规则」（单刷新）、打开工具窗口自动后台全刷新；规则随项目存 `.idea/favorites.rules.xml`
- **收藏分组（1.5.0）**：收藏列表升级多层级分组——分组可挂子分组（层级不限），树按分组层级嵌套展示；删除分组级联删除全部后代分组（组内收藏并入默认列表，不丢数据）；"移动到列表"按分组层级嵌套菜单；添加收藏弹「作用域+分组」树选择弹窗（记住上次作用域与分组、批量只弹一次、原生快捷键路径免弹窗直接进上次分组）
- **行收藏实时内容（1.5.0）**：行收藏显示所在行代码（`行号: 行内容`），文件变动时实时刷新（缓存优先/异步加载/VFS 监听防抖）；修复同一文件路径显示两个文件节点的问题；未识别节点图标兜底
- **匿名收藏**：无限制数量的收藏，在编辑器行号区域显示书签图标（同时匹配项目/全局两个作用域）
- **助记符收藏**：使用数字（0-9）或字母（A-Z）作为标识符，最多36个；助记符在所属作用域内全局唯一（跨列表），跳转快捷键先查项目作用域、再查全局作用域
- **收藏管理工具窗口**：PhpStorm 风格树状视图 + 实时过滤（含作用域名）+ 排序（按列表记忆，两作用域独立）+ 速度搜索 + 收藏设置按钮
- **收藏树交互（1.7.2）**：右键收藏的文件/文件夹/真实目录新增「项目视图操作」子菜单——直接复用平台项目视图动作，并注入与右键节点一致的 DataContext，删除/重命名/新建等动作作用在右键目标而不是项目视图旧选区；工具栏「全部折叠」后新增「刷新」按钮（异步刷新收藏路径的 VFS 后重建树，保留展开记忆与过滤词），文件夹收藏/真实目录右键可「刷新此目录」；「编辑描述」改名为「重命名别名」，别名立即可见（文件/文件夹主文本、行收藏灰色说明、tooltip 原名/路径/别名）
- **快速访问**：弹出窗口快速跳转到收藏位置（按「项目收藏」「全局收藏」分组，组内按「父组/子组」完整分组路径展示）
- **导入原生书签**：一键导入 PhpStorm 原生书签（运行时 API + .idea XML 容错解析双通道，自动去重、增量合并，助记符随迁）
- **收藏路径宏解析与打开失败提示（1.7.3）**：原生书签导入的收藏支持展开 `$APPLICATION_CONFIG_DIR$` / `$USER_HOME$` / `$PROJECT_DIR$` 等 IDE 路径宏（导入期展开 + 项目内外路径归约）；历史遗留的未展开宏路径（如 `file://$APPLICATION_CONFIG_DIR$/consoles/xxx/console.sql`）在打开时按候选路径自动修复解析，收藏树、快速访问弹窗、助记符跳转三个入口共用同一套「宏展开候选 → 逐候选查 VFS → 每路径一次刷新兜底」解析器；打开失败从静默返回改为明确提示——日志 + 非模态 WARNING 通知（收藏名/原始路径/已尝试候选，超长与条数自动截断），数据库控制台收藏另有按控制台 id 在 IDE 配置目录 `consoles` 下兜底查找
- **原生书签快捷键接管**：F11/Ctrl+F11/Shift+F11/Alt+2/Ctrl+0-9 与 Ctrl+点击行号区/图标区手势**始终**由本插件接管（与设置开关无关）；其中**键盘快捷键与 Ctrl+点击手势**固定为「当前项目」收藏、不弹作用域选择，而**菜单/工具栏/右键菜单等入口**弹「作用域+列表」选择（1.7.2 起）；「隐藏 PhpStorm 原生书签界面」开关只控制原生 Bookmarks 工具窗口与残余原生动作的显隐
- **多入口支持**：编辑器右键、行号区右键、项目视图右键、编辑器标签页右键、导航栏右键均有"收藏"子菜单；子菜单首位为「收藏文件夹/收藏文件」直捷动作（文案按选中类型动态显示：收藏文件夹/收藏文件/收藏，行为与"添加收藏"的文件上下文一致：弹「作用域+分组」选择、记住上次、多选批量一次、已收藏切换移除）；「导入原生书签」已收编为顶层动作，不再出现在右键子菜单（入口：收藏工具窗口工具栏按钮与「查找操作 Ctrl+Shift+A」）
- **旧数据迁移**：升级后旧 favorites.xml 中无列表信息的收藏自动归入默认列表，不丢数据

## 使用说明

### 支持的收藏类型

- **匿名收藏**：
  - 无标识符，数量不限
  - 推荐用于临时标记、审查点、调试观察点等
- **助记符收藏**：
  - 使用数字 `0-9` 和字母 `A-Z` 作为标识符（最多 36 个，所属作用域内全局唯一）
  - 推荐用于常驻、需要快速跳转的位置

### 双作用域（1.2.0）

- **项目收藏**：保存在 `.idea/favorites.xml`，随项目走，换台电脑/换个项目不跟随
- **全局收藏**：保存在 IDE 配置目录 `favorites.global.xml`，跨项目共享（存绝对路径，可在任何项目中跳转）
- **添加时选择**：添加收藏/助记收藏时弹出「作用域+分组」树选择（1.5.0 起，见「收藏分组」小节），默认高亮上次使用的作用域与分组并自动记住；项目视图多选批量只弹一次选择，全部加入同一作用域与分组；同一位置已有收藏时维持原有切换（直接移除）语义；**例外**：键盘快捷键（F11/Ctrl+F11）与 Ctrl+点击行号区手势固定加入「当前项目」收藏并直接进上次分组，不弹选择（1.7.2 起菜单/工具栏等非快捷键入口统一弹选择）
- **跨作用域转移**：右键收藏 → "移动到列表" → 展开另一作用域的列表组选择目标列表；全局→项目时若收藏位于项目目录之外会提示失败；转移后助记符在目标作用域冲突时自动降级为匿名收藏

### 共享收藏（1.7.0 引入，1.7.1 改版为配置来源项目）

- **是什么**：介于「项目收藏」与「全局收藏」之间的第三作用域——自己的共享收藏按项目分集合存放于 IDE 配置目录 `favorites.shared.xml`（存绝对路径，可写）；同时可为项目配置若干**来源项目**，共享收藏根下逐来源项目只读显示该来源项目的**项目收藏**。工具窗口树根顺序：项目收藏 → 共享收藏 → 全局收藏 → 规则匹配，共享根下按集合分组（自己的显示「我的共享（项目名）」，来源项目显示「共享自：来源项目」）
- **怎么共享**：添加收藏/助记收藏时在「作用域+分组」弹窗选择「共享收藏」即可（写入自己的集合，路径按绝对路径保存）；自己的集合节点显示为「我的共享（项目名）」
- **怎么配置来源项目（1.7.1）**：工具窗口工具栏「配置共享项目」按钮（或右键共享收藏根/集合节点 → "配置共享项目…"）打开对话框，列出 **IDE 全部已知项目**（含历史已关闭项目，不只打开中的），列=配置勾选/项目名/项目路径/状态（打开中/已关闭）/项目收藏条数（未打开项目解析其 `.idea/favorites.xml` 统计，解析失败显示 -）；**不能选择当前项目自身**（单向选择）；列表上方「刷新」按钮重新扫描项目列表与条数；「保存」后立即刷新收藏树；来源项目节点右键可「移除共享项目」，自己集合节点右键可「取消共享…」（确认框警示会删除共享数据）
- **单向只读（1.7.1）**：仅消费方保存配置，**被共享项目不需要任何开启/配置动作**；来源项目已打开时实时读其项目收藏（BookmarkManager 实时数据），未打开时解析其 `.idea/favorites.xml`（文件变更后手动刷新可见；路径已不存在的项目照常显示、条数列 "-"、树中节点为空并有 tooltip 提示）；全程绝不写来源项目的任何文件；来源收藏为只读镜像（删除/重命名别名/设置助记符/分组写操作均有只读保护）
- **旧数据迁移（1.7.1）**：1.7.0 的旧订阅引用（按集合 id）在首次读取时自动映射回来源项目路径转为来源项目配置（映射不到的丢弃），自己的共享收藏数据不受影响
- **实时可见**：项目 a 里增删改自己的共享收藏后，其它项目窗口的收藏树/gutter 即时刷新（同 IDE 进程经消息总线广播；跨 IDE 进程由后台 mtime 轮询兜底）
- **与项目/全局收藏的区别**：项目收藏随项目走、只在本项目可见；全局收藏随 IDE 应用走、所有项目直接可见（无来源概念）；共享收藏介于两者之间——自己的集合随 IDE 应用可写，来源项目收藏按项目分组只读镜像显示
- **三作用域互相切换**：右键收藏 → "移动到列表" → 展开「项目收藏/共享收藏/全局收藏」任意目标分组；→共享/全局转绝对路径，→项目仅当路径位于项目内才转相对（否则提示失败）；任何作用域 → 共享为**移动**（写入自己的集合）；外来共享（来源项目节点下）→ 其它作用域为**复制**（源保留不删）；助记符冲突自动降级为匿名收藏
- **文件变动同步**：项目内文件删除/移动/重命名时，自动清理/更新自己集合内对应的共享收藏（来源项目镜像不动）

### 收藏列表

- 新建列表：工具窗口右键 → "新建列表"（选中作用域节点或默认列表"收藏"时=新建顶级列表）
- 新建子分组（1.5.0）：右键某个分组 → "新建子分组"，子分组可继续嵌套（层级不限）
- 重命名列表：右键列表（或列表中的收藏）→ "重命名列表"（默认列表"收藏"不可重命名，改名后子分组的完整路径跟随更新）
- 删除列表：右键列表 → "删除列表"，**级联删除其全部后代子分组**，其中的收藏自动并入默认列表，**不会丢失数据**（确认框列明连删子分组数与并入收藏数）
- 移动收藏：右键收藏 → "移动到列表" → 按作用域分组、按分组层级嵌套展示选择目标（支持跨作用域转移）
- 排序：工具窗口右上角排序下拉（按添加顺序 / 按描述 / 按位置），**按列表记忆并持久化**（两个作用域各自独立）

### 收藏分组（1.5.0）

- **多层级分组**：分组可挂子分组、层级不限；工具窗口树按 作用域 → 分组 → 子分组 嵌套展示，分组徽标显示自身收藏数，搜索命中分组名时放行整棵子树
- **新建子分组**：右键分组 → "新建子分组"（右键作用域节点或默认列表"收藏"=新建顶级列表）；默认列表"收藏"只能作顶级，不可作子分组
- **级联删除语义**：删除分组时其全部后代子分组一并删除，组内收藏并入默认列表"收藏"（确认框列明连删子分组数与并入收藏数），**不丢数据**
- **迁移兼容**：旧 favorites.xml / favorites.global.xml 无分组 id 自动补全；parentId 指向缺失/指向自己/成环自动归顶级，默认列表"收藏"强制顶级
- **添加时分组树选择**：添加收藏/助记收藏弹「作用域+分组」树弹窗（项目/全局两作用域为根、分组按层级展开），自带输入即过滤，Enter/双击确认、Esc 取消不添加
- **记住上次**：按作用域各自记住上次选择的分组，下次打开默认高亮并滚动到位；所选分组已被删除时回退默认列表"收藏"
- **批量一次**：项目视图多选批量添加只弹一次选择，全部加入同一作用域与分组
- **快捷键路径免弹窗**：键盘快捷键（F11/Ctrl+F11）与 Ctrl+点击行号区手势固定加入「当前项目」收藏，并直接写入上次使用的分组（无记忆时进默认列表"收藏"），全程不弹选择；**菜单/工具栏等非快捷键入口**照常弹「作用域+分组」选择（1.7.2 起统一）
- **快速访问显示路径**：`Ctrl+Alt+Shift+B` 弹窗内分组条目按「父组/子组 (N)」完整分组路径平铺展示

### 快捷键（默认键位）

| 功能 | 默认键位 |
|---|---|
| 添加/移除收藏（编辑器上下文） | `Ctrl+Alt+F11` |
| 添加/移除助记收藏（编辑器上下文） | `Ctrl+Alt+Shift+F11` |
| 显示/隐藏收藏工具窗口 | `Alt+2` |
| 显示收藏弹出列表 | `Ctrl+Alt+Shift+B` |
| 跳转到助记符收藏 [0-9, A-Z] | `Ctrl+Alt+0-9` / `Ctrl+Alt+A-Z` |
| 工具窗口内：跳转 | `Enter` / 双击 |
| 工具窗口内：重命名别名 | `F2` |
| 工具窗口内：删除 | `Del` |

> 说明：PhpStorm 原生书签的以下键位由本插件**无条件接管**（与设置开关无关；原生动作 id 不变，用户自定义键位映射保留）：
>
> | 原生键位 | 原生动作 id | 接管后行为 |
> |---|---|---|
> | `F11` | `ToggleBookmark` | 当前项目匿名收藏切换（不弹作用域选择，写入上次分组） |
> | `Ctrl+F11` | `ToggleBookmarkWithMnemonic` | 当前项目助记符收藏（不弹作用域选择，写入上次分组） |
> | `Shift+F11` | `ShowBookmarks` | 收藏弹出列表 |
> | `Alt+2` | `ActivateBookmarksToolWindow` | 收藏工具窗口开关 |
> | `Ctrl+0-9`（存在时含 `Ctrl+A-Z`） | `GotoBookmark0-9`（`GotoBookmarkA-Z`） | 跳转到对应助记符收藏 |
> | `Ctrl+点击` 行号区/图标区（Mac 为 ⌘+点击） | ——（原生为硬编码鼠标手势，非动作；1.5.0 起经 `EditorMouseListener` 在 mousePressed 消费接管） | 当前项目匿名收藏切换（点击行，不弹作用域选择） |
>
> 快捷键与手势**始终归本插件接管**，不受任何设置开关影响；"隐藏 PhpStorm 原生书签界面"开关**只控制原生书签界面的显隐**——
> 残余原生动作（`ToggleBookmark0-9`/`ToggleBookmarkA-Z`/`ShowTypeBookmarks` 等）、原生 `Bookmarks`
> 动作组与原生 `Bookmarks` 工具窗口的可见性。

### 规则匹配（1.4.0）

**入口**：收藏工具窗口树第一层第三根节点「规则匹配」（与「项目收藏」「全局收藏」同级）。工具栏「新建规则」创建；右键规则 → 刷新此规则 / 编辑规则 / 启用|禁用 / 删除规则；规则编辑对话框底部「测试」按钮用当前表单值直接试跑并弹结果预览（不写入树结果）。

**刷新入口**：

- 工具栏「刷新规则」：全部规则后台重刷（全刷新）
- 右键规则 →「刷新此规则」：仅刷新该规则（单刷新）
- 打开工具窗口：自动后台全刷新
- 禁用的规则不参与刷新，重新启用时自动执行一次
- 规则节点状态徽标：`✅ N`（成功，N=结果条数）、`⏳`（执行中）、`❌`（失败，tooltip 显示失败原因）

**三类规则字段与用法**：

- **正则规则**：
  - 匹配目录：起始目录相对路径（留空=项目根）
  - 正则表达式：对项目内文件/文件夹的相对路径（`/` 分隔、无前导斜杠）做 find 匹配
  - 匹配目标：仅文件 / 仅文件夹 / 全部；忽略大小写：可选
  - 结果上限：达上限即停止遍历（硬上限 10000），防止大项目卡顿
  - 结果可跳转：文件→编辑器打开，文件夹→Project 视图选中
- **SQL 规则**：
  - 连接方式二选一：「IDE 数据源」（选 IDE Database 工具窗已配置的数据源，复用其连接与密码）或「手动 JDBC」（URL/用户名/密码；密码经 PasswordSafe 安全存储不落盘，编辑留空=保留原密码）
  - SQL 查询：SELECT 语句，结果按行列展示
  - 路径列（可选）：填查询结果中的列名，该列的值作为跳转目标（文件→编辑器打开，目录→Project 视图选中）
  - > 提示：手动 JDBC 依赖 IDE Database 工具窗对应数据库的驱动**已下载**；驱动缺失时插件会尝试从 IDE 已下载驱动目录或指定驱动 jar 动态加载兜底
- **SSH 规则**：
  - 主机：选 IDE SSH Configurations 或 `~/.ssh/config` 中已有的主机别名（双通道读取，别名去重），或手动填 主机/端口/用户名
  - 自定义命令：在远程主机执行，输出按行展示为结果条目
  - **v1 限制**：仅支持密钥/agent 认证（本机 ssh 命令 BatchMode 执行，禁用交互提示），**不支持密码登录**
  - 结果为纯展示（不可跳转），双击/右键「查看详情」可看完整内容

**结果条目交互**：可跳转条目（正则文件/文件夹、SQL 路径列）双击/Enter/右键「跳转」；SQL 行/SSH 行双击或右键「查看详情」弹信息框展示完整内容。

**存储位置**：规则（名称/启用状态与各类参数）随项目保存在 `.idea/favorites.rules.xml`，随项目走；SQL 手动连接的密码除外（经 PasswordSafe 存入 IDE 凭据库，不落项目文件）。

## 构建说明

### 方式一：使用 IntelliJ IDEA（推荐）

1. 在 IntelliJ IDEA 中打开项目
2. IDE 会自动下载 Gradle wrapper
3. 在 Gradle 工具窗口中运行 `buildPlugin` 任务
4. 插件包将生成在 `build/distributions/` 目录，并自动同步复制到项目根 `distributions/` 目录

### 方式二：使用命令行

```bash
# Windows
gradlew.bat buildPlugin

# Linux/macOS
./gradlew buildPlugin
```

### 方式三：使用便捷打包脚本 bin/build.sh（推荐）

脚本自动定位 JDK17（JAVA_HOME → PATH → /usr/lib/jvm/java-17*）并执行 Gradle 打包：

```bash
# 默认执行 buildPlugin
bash bin/build.sh

# 先跑单元测试再打包
bash bin/build.sh --test

# 打包前先 clean；其余参数原样透传给 gradlew
bash bin/build.sh --clean
bash bin/build.sh --clean --test
bash bin/build.sh --clean buildPlugin --console=plain
```

构建成功后打印插件 zip 的绝对路径、大小与 sha256。zip 会同步输出到项目根 `distributions/` 目录（`build/distributions/` 仍是 Gradle 原始输出位置，CI 发布继续使用它）。

## 安装插件

1. 构建完成后，在项目根 `distributions/`（或 `build/distributions/`）目录找到生成的 zip 文件
2. 在 PhpStorm 中：`File` -> `Settings` -> `Plugins` -> `Install Plugin from Disk`
3. 选择生成的 zip 文件进行安装
4. 重启 PhpStorm
